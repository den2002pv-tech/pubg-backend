# Scanner usage guide assets

Place public guide media in this directory:

- `01-open-collection.png` — where to find the card collection in PUBG Mobile.
- `02-album-screenshot.png` — example of a correctly framed album screenshot.
- `03-send-to-bot.gif` — how to send the screenshot to the scanner bot.
- `04-scan-result.png` — example of the scan result.
- `05-card-sync.gif` — optional card synchronization walkthrough.

## File naming

Use lowercase English names, hyphens instead of spaces, and a numeric prefix to preserve the display order. Use `.png` or `.webp` for screenshots and `.gif` for short animations. Keep original source files when editing; add revised versions as new files rather than overwriting originals.
