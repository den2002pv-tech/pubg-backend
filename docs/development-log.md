# Журнал разработки

Документ фиксирует заметные подтверждённые улучшения проекта. Это не полный перечень каждого коммита. Даты указаны по истории Git; статус проверки приводится только там, где он был фактически установлен.

## 2026-10-14 — надёжность JavaScript и проверки CI

- Исправлена синтаксическая ошибка в `admin.html`: буквальные символы `\\n` вместо настоящего переноса строки ломали встроенный JavaScript и могли остановить обработчики страницы, включая вход администратора.
- Добавлен `scripts/check_inline_js.cjs`: проверяет синтаксис встроенных классических JavaScript-блоков во всех HTML-файлах.
- Проверка добавлена в оба workflow: `.github/workflows/tests.yml` и `.github/workflows/counter-tests.yml`; используется Node.js 22.
- Цель улучшения — обнаруживать синтаксические ошибки интерфейса до завершения CI, а не только проверять Python-код.
- Ограничение: проверка компилирует код, но не исполняет его в браузере. Она не доказывает работоспособность авторизации, DOM-событий, запросов API или всей пользовательской последовательности.
- Подтверждённая локальная проверка исходного исправления: встроенный JavaScript `admin.html` был скомпилирован без синтаксической ошибки. Для новых коммитов с проверкой CI необходимо отдельно сверить результат workflow по SHA; запуск и успешное прохождение новых workflow на момент записи не подтверждены.

- Проверка встроенного JavaScript: [3884833](https://github.com/den2002pv-tech/pubg-backend/commit/3884833b789698471d5638183d6add455ec1ecb9).
- Подключение проверки к основному workflow: [2567b0d](https://github.com/den2002pv-tech/pubg-backend/commit/2567b0d7a8005758324e33888a208fb722acd281).

## Правило ведения журнала

При заметном изменении добавляйте запись в этот файл в том же PR/наборе изменений:
1. Дата и краткая цель.
2. Что добавлено или улучшено и какие компоненты затронуты.
3. Какие проверки действительно запускались и каков их результат.
4. Ограничения и сценарии, которые ещё не проверены.
5. Ссылки на коммиты, если они доступны.

Не записывайте предположения как факты. Если CI или развёртывание ещё выполняется либо недоступно для проверки, прямо указывайте это.
