# Архитектура

## Область документа

Описание сверено с исходниками ветки `feature/card-counter`. Это карта основных компонентов, а не полный контракт API. Точные маршруты и условия авторизации будут описаны отдельно после пофайловой проверки всех обработчиков.

## Компоненты

### HTTP-приложение — `main.py`

- Создаёт приложение FastAPI с названием `PUBG Card Scanner`.
- При старте инициализирует БД, выполняет миграционную логику хэшей и синхронизирует каталог карточек.
- Регистрирует маршруты заявок на обмен из `trade_requests.py`.
- Проверяет Telegram Web App init data для пользовательских запросов.
- Подключает Sentry только при наличии непустого `SENTRY_DSN`; `send_default_pii=False`.
- Содержит API-обработчики и раздачу части интерфейса/статических ресурсов.

### Распознавание — `scanner.py`

Модуль использует OpenCV, NumPy, Pillow и ImageHash. Код включает геометрический поиск карточек на изображении и функции сканирования/обнаружения карточек. Подробный алгоритм распознавания счётчика и этапы сохранения количества документируются отдельно после проверки соответствующих функций и тестов.

### Данные — `database.py`

- Подключается к PostgreSQL через `psycopg`.
- Получает строку подключения из переменной окружения `DATABASE_URL`; при её отсутствии выбрасывает ошибку.
- Инициализирует таблицы и индексы приложения.
- Обрабатывает пользователей, карточки, количество в инвентаре, список «Ищу» и данные активности.

### Обмены — `trade_requests.py`

Отдельный модуль FastAPI-router для заявок на обмен. Зависимости авторизации, получения пользователя, поиска совпадений и отправки уведомлений передаются через `register_trade_request_routes(...)`. Подробная машина состояний и требования к передаче кода должны описываться по фактическим проверкам обработчиков и тестов, а не только по текстам кнопок.

### Интерфейсы

- `index.html` — основной интерфейс приложения.
- `admin.html` — административный интерфейс, включая управление/просмотр пользователей.
- Репозиторий содержит `card_hashes.json` с данными хэшей карточек.

Файлы HTML крупные и содержат клиентскую логику. При изменении интерфейса проследите полный путь от действия пользователя до API и обработки ответа.

## Хранилище

Основные таблицы, создаваемые в `database.py`, включают:

- `users` — Telegram ID, профиль и отметки активности.
- `cards` — каталог карточек.
- `user_cards` — связь пользователя и карточки с количеством; первичный ключ составной (`user_id`, `card_id`), количество ограничено значениями не меньше нуля.
- `desired_cards` — список «Ищу» пользователя; первичный ключ составной (`user_id`, `card_id`).
- `trades` — базовая таблица старой/общей модели обменов, объявленная в `database.py`.
- `trade_requests` — схема заявок на обмен инициализируется в модуле `trade_requests.py`.

Наличие таблицы `trades` в инициализации не означает, что текущий сценарий заявок использует её вместо `trade_requests`. Перед изменением схемы выясните, какие запросы реально обращаются к каждой таблице.

## Потоки, которые нужно рассматривать целиком

1. **Сканирование:** загрузка изображения → обработка/обнаружение карточек → распознавание количества → API-ответ → сохранение/обновление инвентаря.
2. **Коллекция:** пользователь и стабильный ID карточки → количество в `user_cards` → состояние списка `desired_cards` → отображение и фильтры.
3. **Обмен:** создание заявки → согласие участников → передача кода → подтверждение завершения обоими участниками → изменение инвентаря. Точные допустимые переходы должны быть подтверждены кодом и тестами; не считайте текст интерфейса доказательством серверной проверки.
4. **Активность:** запросы Mini App обновляют отметки активности; административная выборка рассчитывает онлайн-статус относительно временного окна.

## Инфраструктура и ограничения подтверждения

В репозитории есть workflow GitHub Actions для тестов. Внешняя конфигурация Render, Vercel и Sentry не полностью описывается кодом. Секреты, реальные URL окружений и значения токенов в документацию не помещайте; для внешних настроек используйте панели соответствующих сервисов и переменные окружения.
