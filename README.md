# PUBG Card Scanner

Backend для приложения управления коллекцией и обменом карт PUBG Mobile. Репозиторий содержит FastAPI-приложение, распознавание карточек на скриншотах, PostgreSQL-доступ, Telegram Mini App API и статические HTML-интерфейсы.

> Эта документация сверяется с кодом ветки `feature/card-counter`. Если документ расходится с кодом, сначала проверьте реализацию и тесты, затем исправьте документацию или код — не полагайтесь на устаревшее описание.

## Основные файлы

- `main.py` — FastAPI-приложение, Telegram WebApp-авторизация, обработчики API и статические маршруты.
- `scanner.py` — обработка изображений, обнаружение карточек и распознавание количества.
- `database.py` — PostgreSQL-схема и операции с пользователями, карточками, инвентарём и списком «Ищу».
- `trade_requests.py` — маршруты и бизнес-логика заявок на обмен.
- `index.html` — основной интерфейс Mini App.
- `admin.html` — интерфейс администратора.
- `card_hashes.json` — данные хэшей карточек; перед изменением изучите процесс их формирования и использования.

- Не добавляйте секреты и реальные пользовательские данные в репозиторий.
