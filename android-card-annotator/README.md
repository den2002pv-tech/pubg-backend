# PUBG Card Boundary Annotator (Android)

Android-приложение для разметки границ карточек на скриншотах PUBG Mobile.

- Выбор изображения из галереи; обработка выполняется локально на телефоне.
- Автопоиск прямоугольных контуров с OpenCV.
- Ручное добавление рамки свайпом по диагонали карты.
- Удаление последней рамки и экспорт координат в JSON через системное меню «Поделиться».

Автоматические рамки — только кандидаты, их нужно проверить. В этой версии рамки нельзя перемещать или менять размер после создания: неверную последнюю рамку можно удалить и нарисовать заново.

## Сборка

JDK 17 и Android SDK 35. Откройте папку в Android Studio и запустите assembleDebug. Workflow Android APK собирает debug APK при изменениях этой папки или вручную; готовый файл прикрепляется к запуску workflow как артефакт.

Координаты JSON относятся к изображению, уменьшенному до максимальной стороны 1800 пикселей, начало координат — левый верхний угол.
