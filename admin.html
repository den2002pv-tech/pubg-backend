Создание хешей

Текущий процесс оставлен: загрузи скриншот коллекции, проверь найденные карточки и сохрани их в card_hashes.json.

Найденные карточки

После каждого сканирования введи реальные количества и добавь примеры в очередь. Очередь хранится в этом браузере; новые сканирования её не очищают. Render и GitHub не перезапускаются на каждом наборе из 4 карт.

Реальные тесты счётчика

Сначала на вкладке «Хеши» добавляй результаты каждого сканирования в очередь. Когда закончишь тестирование, нажми «Отправить всю очередь одним commit». В GitHub попадут изображения, введённые эталонные количества и диагностика всех накопленных примеров за один commit. Очередь сохраняется в текущей вкладке браузера до отправки или очистки данных браузера.
