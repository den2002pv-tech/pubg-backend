Создание хешей

Загрузи скриншот коллекции один раз. При добавлении новой карты хеши и постоянная иконка сохраняются из одного и того же изображения — повторно загружать его не нужно.

Найденные карточки

Добавляй карты со всех нужных скриншотов. Иконки и хеши сохраняются на сервере по мере подтверждения, но в GitHub ничего не отправляется автоматически. Когда закончишь добавлять все изображения, нажми «Отправить все изменения одним commit» на вкладке «Карты».

Реальные тесты счётчика

Эталоны хранятся в GitHub. Открой меню ⋯ у теста, чтобы изменить фактическое количество или удалить пример вместе с кропом. Изменения сохраняются отдельным commit в рабочую ветку.

Регрессионные тесты

Запускает распознавание на всех сохранённых эталонных кропах из выбранной ветки. Сравнивает новый результат с эталонным количеством и показывает ошибки и диагностику. Запуск не меняет карты, эталоны, инвентарь или метрики.

Иконки карт

Для новых карт загружай скриншот только на вкладке «Хеши»: постоянная иконка сохранится из него автоматически. Эта вкладка нужна, если требуется вручную добавить или заменить иконку уже существующей карты.

База карт

Все изменения карт и постоянных иконок накапливаются на сервере. Отправь их в рабочую ветку одним commit только после того, как закончишь сканировать и добавлять изображения.
