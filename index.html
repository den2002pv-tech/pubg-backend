Справка по обозначениям

Так выглядит карточка в результатах сканирования.

×4 ×4 ✓ ×2
  • ↖Слева сверху — количество для сохранения. Сначала равно числу со скриншота; при ручной правке меняется.
  • ↗Справа сверху — счётчик из самой игры, по нему сканер определил количество. Нет счётчика — слева будет ×1.
  • ↙Слева снизу — сколько копий уже в инвентаре. ×0 — карты нет, «?» — не распознана и не сохранится.
  • ↘Справа снизу — эталон из каталога. Нажмите, чтобы сравнить со скриншотом.
  • ✓Выбрать — сохранить карту в инвентарь. Сохраняются только отмеченные.
  • 4Число рядом — сколько копий сохранить. Исправьте, если сканер ошибся: оно заменит текущее количество, а не прибавится.
  • дубл.После: ×4 · дубл.: 3 — итог после сохранения; дубликаты — копии сверх одной.
